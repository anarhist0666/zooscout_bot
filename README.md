# ZooScout (ТГ username - @Zoo_Scout_bot)

**Платформа для содействия устройству домашних животных в ответственные руки**

## Обзор проекта

ZooScout представляет собой специализированное программное решение, реализованное в формате Telegram-бота, предназначенное для оптимизации процесса поиска новых владельцев для домашних животных. Проект направлен на создание эффективной коммуникационной среды между текущими владельцами животных и потенциальными adopters.

## Функциональные возможности

### Система управления профилями
- Регистрация пользователей в качестве физических лиц или юридических образований
- Создание расширенных профилей с контактной информацией
- Раздельное управление персональными данными и данными организаций

### Каталог животных
- Структурированная база данных животных по категориям: собаки, кошки, другие виды
- Детализированные анкеты с фотографиями и описательными характеристиками
- Система фильтрации и последовательного просмотра анкет

### Инструменты взаимодействия
- Механизм добавления анкет в персональный список интересов
- Прямой доступ к контактной информации владельцев
- Система управления созданным контентом

## Техническая архитектура

### Компоненты системы
- **Интерфейс взаимодействия**: Telegram Bot API
- **Слой данных**: SQLite с использованием SQLAlchemy ORM
- **Бизнес-логика**: Модульная структура на Python
- **Состояния сессий**: Конечные автоматы для управления диалогами

### Модели данных
- Пользовательские аккаунты с привязкой к Telegram
- Профили физических лиц и организаций
- Каталог животных с медиа-вложениями
- Система отметок интереса

## Целевая аудитория
